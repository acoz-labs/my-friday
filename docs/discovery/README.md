# Product Discovery Packs

Use one temporary directory per discovery issue:

```text
docs/discovery/<issue>-<slug>/
  README.md
  optional supporting Markdown files
```

The README must remain a complete, self-contained decision. Supporting files
may deepen sanitized context, evidence, experience, or outcome decomposition;
they may not introduce private URLs, filesystem paths, credentials, or required
private execution context. Represent private material only through sanitized
claims and opaque IDs that are unnecessary for delivery execution.

After exact-head approval, merge, and outcome materialization, promote any
still-current product decision into durable repository documentation and delete
the whole discovery pack in a reviewed cleanup. The merged pull request and Git
history retain provenance.
